#                  UI info panel and read aloud on arrival. Uses underscores
#                  instead of spaces (replaced at load time). Optional for
#                  non-artifact waypoints.
#
# NAMING CONVENTIONS (navigation_node uses prefix matching):
#   artifact_*   — gallery artefact POIs
#   toilet_*     — toilet / bathroom locations  (nearest-toilet logic)
#   fire_exit_*  — emergency exits              (nearest-fire-exit logic)
#   home         — robot home / charging station
#

#   Navigable area:  X [-0.90, +0.85]   Y [-0.86, +0.59]

#   1. Launch the full Nav2 stack with AMCL against the real gallery map.
#   2. Drive the robot to each POI using teleop.
#   3. Record the AMCL pose:
#        ros2 topic echo /amcl_pose --once
#      Copy position.x, position.y.
#   4. Replace coordinates below.
#   5. Restart the navigation_node — no rebuild needed.
#
